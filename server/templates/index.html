GET STARTED

创建你的课表订阅

上传本机采集的课表，获取专属订阅链接。

密码只输入学校页面。手机采集后上传课表，本站不接收登录 Cookie；以后更新需重新采集并上传，订阅链接保持不变。

  1. 安装脚本管理器：iPhone/iPad：Userscripts · Android Firefox：Violentmonkey，仅授权本科教务网站。
  2. 打开安装本机课表采集脚本，通过脚本管理器确认安装。
  3. 在学校官方页面登录并进入本科教务页，打开右下角“ZJU Calendar 本机采集”，选学期和内容后采集并复制。
  4. 回到此处粘贴，核对后上传。再次更新时，先用管理密钥进入原订阅，再上传新快照。

当前支持本科课程与考试。手机实机兼容性待验证；如果学校接口或脚本权限不匹配，采集会停止，不会上传部分数据。

导入会话 JSON（电脑 / Android Firefox）

iPhone/iPad 上当前 Cookie-Editor 无法读取所需的 HttpOnly JSESSIONID，此路径不可用。请使用上方“手机本机采集”，不要反复尝试导出。

其他受支持浏览器可安装 Cookie-Editor，仅授权它访问 zdbk.zju.edu.cn。

  1. 通过下方学校官方登录入口登录，进入本科教务页面。
  2. 在教务页打开 Cookie-Editor，选择导出 JSON 并复制。
  3. 回到这里粘贴并读取，填写学号后创建订阅。

只在本机读取域名和路径匹配的教务会话；其余 Cookie（包括全局 SSO）会丢弃。点击创建订阅前不会上传。原始导出内容不会保存。研究生仍请提供系统 X-Access-Token。

用本机账号密码获取会话

在本机助手中输入账号密码，只向学校认证。下载并解压后，按包内“使用说明.txt”运行；需要 Python 3.12 或更高版本。

下载本机登录助手

密码不回显、不写入会话文件，也不会上传至本站。学校要求验证码或二次认证时，可使用下方官方登录方式。

文件在本机读取，仅填入下方表单。检查学号、选择学期并同意保存后，点击“创建订阅”才上传教务会话。导入后可自行删除本机会话文件。
